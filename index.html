The system

Three layers. None of them works alone.

  1. 01 / INDEX

    An address for everywhere — that survives

    A hierarchical code for any point on Earth, from region down to doorway. Generating codes was never the hard part; the hard part is that places change. Settlements grow, boundaries move, governments turn over. GRID's codes carry a lifecycle, so a location keeps its address through all of it instead of being reshuffled at the next regeneration.

    We call it the genesis lock. It is the most differentiated thing we own, and the thing addressing procurements discover they needed about two years too late.

  2. 02 / FORMAT

    Scenes that stay queryable while compressed

    Ask a compressed 3D scene a question without unpacking it — one street, one moment, one bounding box. The specification is published openly, with independent reader implementations in Python and JavaScript, so whoever builds on it can read their own data forever, with or without us.

    Open on purpose. A government that cannot read its own address layer does not own it.

  3. 03 / ADAPTERS

    Ten of them, against one index

    Addressing, flood, crowds, volumetric, worldgen, climate, medical, robotics, splats, synthetic worlds. Because they share an index, a result from one is addressable by the next — which is the part competitors rebuild five times over.

Capability

An address is only useful if something runs on it.

Addressing is the floor, not the product. Every adapter reads and writes against the same index, so the flood model knows which buildings, the crowd model knows which streets, and the machine knows which doorway.

Addressing

Resolve any point on Earth down a hierarchy to a code that persists when the place around it changes.

Flood

Water over real terrain, reported by the addresses it reaches rather than by a grid square.

Crowds

Density and failure points on the real geometry of a real place, before the gate opens rather than after.

Robotics

Train at a code in simulation, deploy to the same code in the world, and the machine knows where it is standing.

Six more adapters run on the same engine — volumetric, worldgen, climate, medical, splats, synthetic worlds. These are diagrams of what each one does, not readings from live data.
